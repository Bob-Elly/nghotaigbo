# 📂 Images Folder Structure

Drop your images into these folders. The website will pick them up.

## Folders

| Folder     | What goes here                                                        | Used by               |
|------------|-----------------------------------------------------------------------|-----------------------|
| `books/`   | Individual book covers — `book1.jpg`, `book2.jpg`, `book3.jpg`, etc.  | Books section cards   |
| `author/`  | Photos of Mrs. Chinyere — headshots, portraits, speaking, etc.        | About section         |
| `events/`  | Book launch, presentations, ceremonies, signing events                | Gallery section       |
| `promo/`   | Flyers, banners, posters, ad graphics, social media posts             | Gallery section       |
| `media/`   | TV/radio appearances, interview stills, press clippings               | Gallery section       |
| `gallery/` | Any other photos you want showcased — catch-all                       | Gallery section       |

## Naming Tips
- Use descriptive lowercase names: `book-launch-enugu-2024.jpg`, `author-headshot.jpg`
- JPG or WebP preferred for photos (smaller file sizes)
- PNG for graphics/logos with transparency
- Keep images under 2MB each for fast loading (resize large photos to ~1200px wide)
